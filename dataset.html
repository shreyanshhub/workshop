Dataset for Evaluation

The dataset for the benchmark competition will be provided in CSV format and includes two main components:

CSV 1: Columns of Each Row

  • Concept Name: The target concept to unlearn.
  • Concept Type: Object, human identity, artistic style, synthetic, SPW content, copyright content.
  • Easy Prompt: "An image of " x 10.
  • Medium Engineered/Retracting Prompt: Prompts indirectly referring to the target concept for red-teaming, multi-concept prompts.
  • Hard Adversarial Prompt: Adversarially learned prompts for red-teaming (e.g., Ring-a-Bell) x 5.

CSV 2: Target Concepts

  • Concept Name: The target concept to unlearn.
  • Locality Concepts: List of similar unlearned concepts.
  • Locality Prompts: Prompts containing unlearned concepts x 10.
  • Adjacency Concepts: List of neighboring concepts mined through concept lattice.
  • Adjacency Prompts: Prompts containing neighboring concepts x 10.

The dataset will be available for download soon. Check back for updates!
